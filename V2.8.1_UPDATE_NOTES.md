# Wasl Mobile 2.8.1+42 — Theme & Navigation Polish

This revision is based on the previous 2.8.0+41 cumulative update.

## Fixed
- Default app accent now follows the teal/mint color of the Wasl logo.
- Dark mode uses a coherent surface system instead of several unrelated Material 3 shades.
- Bottom navigation no longer has the extra rounded backing layer/shadow.
- Content no longer extends behind the bottom navigation.
- Top chat header uses the same page background and no extra shadow layer.
- Default chat background and bubbles follow the active app theme until the user customizes chat appearance.
- Existing custom theme/navigation/chat colors remain supported.
- Recording send action now follows the selected app primary color.
- Splash dark background aligned with the app dark background.
- Included the localization fixes validated after 2.8.0+41 (dynamic conversation wording and missing English strings).

## Apply
Extract this update over the current SupportHub-Mobile project, then run:

    flutter clean
    flutter pub get
    flutter analyze
    flutter test
    flutter run

If custom colors were previously saved, use Settings > Appearance > Reset to see the new Wasl defaults.
