# Wasl Mobile 2.8.3+44

- Reworked the full bottom navigation into a single floating rounded capsule.
- Kept the selected destination as a circular highlight inside the capsule.
- Removed all foreground notification SnackBars/popups.
- Realtime now updates unread counts and the Notifications tab only.
- Mobile Settings now requests native Android/iOS notification permission through Firebase Messaging.
- Existing grants are registered automatically without prompting on login.
- Foreground system presentation is suppressed; background/terminated push remains enabled.
- Unified default light/dark page surfaces; dark mode is neutral charcoal/black, not green-tinted.
- Updated default Android notification channel contract to `wasl_messages` (server patch required).
