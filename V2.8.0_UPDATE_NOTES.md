# Wasl Mobile 2.8.0+41

- Removed the Main Channel block from the mobile home header.
- Merged conversation rows into a cleaner continuous inbox.
- Added a rounded, customizable bottom navigation bar.
- Added store-managed slash quick replies in chat.
- Shows tags and follow-up reminders before opening a conversation.
- Shows the employee who closed a conversation when supplied by the API.
- Keeps existing FCM foreground/background/terminated routing to the exact conversation.
- Preserves filters, AI drafts, media, audio, assignment, tags, and follow-up controls.

- The package keeps the Wasl logo and production API configuration.
- External notifications require valid Firebase dart-defines that match the API project; no credentials are bundled.
- Store owners manage custom replies in the web dashboard; the app only displays the current store replies.
