# Wasl Mobile 2.8.2+43 — Dark Mode, Circular Navigation & In-App Notifications

## Updated
- Default dark mode is now genuinely neutral charcoal/black instead of green-tinted.
- Wasl mint remains the accent for selected items, buttons and interactive states.
- Chat default dark background/bubbles were aligned with the neutral dark palette.
- Bottom navigation selection is now a true circular 44x44 highlight instead of a rectangular indicator.
- Android bottom navigation stays clean and opaque with one surface only.
- iOS-ready navigation uses a restrained blurred translucent surface for a Liquid-Glass-like feel when an iOS target is added later.
- In-app notifications no longer depend only on Firebase foreground delivery: conversation realtime events refresh unread counts and show a banner when unread messages increase.
- Notification banners open the exact conversation.
- FCM foreground and realtime banners share a dedupe gate to prevent double notifications for the same chat.
- Existing notification badge and Notifications screen continue to refresh from conversation realtime events.
- Returning from an opened notification/chat immediately refreshes unread state and badge counts.

## Push notification requirement
Background/terminated push still requires real Firebase build defines and matching server-side FCM credentials. No fake Firebase keys are included.

## Apply
Extract over the current SupportHub-Mobile project, then run:

    flutter clean
    flutter pub get
    flutter analyze
    flutter test
    flutter run
